## Hallazgos adicionales reparados

- **`owned_slugs` ausente:** implementado con ownership inicial/transferencias verificadas. Exportación real sintética vuelve a funcionar; exportación/importación/watchers se prueban.
- **Cómputo vs publicación:** un hijo con exit 0 puede quedar `PUBLICATION_PENDING`; no se marca publicado ni se ejecuta HPO siguiente. `publish` reintenta snapshots sin repetir cómputo. Exportar/recibir ZIP tiene evidencia propia distinta de COMPLETE.
- **Filtros/cola:** selección vacía ya no equivale a todas las arquitecturas; ownership se verifica dentro de claim; tres semillas de una arquitectura no se ejecutan a la vez bajo tres dueños. Límites locales no se presentan como consenso distribuido.
- **Actualización silenciosa:** código/commit, configuración, espacio y modo incompatibles bloquean el uso de una ronda. `mirror-round` verifica config fuente y la identidad científica contra una base local validada antes de escribirla.
- **Pérdida de progreso al transferir:** la oferta transfiere solo estado autorizado de esa arquitectura/ronda, con trials y revisiones; la receptora no repite etapas aprobadas. Un ZIP ordinario no hace esta transición.
- **Figuras/expectativas antiguas:** tests actualizados a rutas derived_v4, seed fija 67, siete modelos, metadatos versionados y autorización posterior al freeze. No se eliminaron assertions para conseguir PASS; se sustituyeron expectativas obsoletas por contratos actuales.
